Software para Educação. No intuito de alunos fazerem resumos do que estão estudando. A pessoa digita um tema e a IA gera 5 perguntas com uma opção correta. No fim mostra pontuação.
Porém no momento o software não esta usando IA, mas um banco de dados (data.js) sem opção de inserir o tema. Mas esse codigo mostra ao usario a resposta certa ou errada quando se clica nas opções. Coloquei uma animação na tela de pontuação, caso o usuário acerte mais de 50%.
Uso de React Vite, Tailwind CSS, HTML, JavaScript.
